{% blocktrans %}Erste Schritte{% endblocktrans %}

{% blocktrans %}Was ist das Portal?{% endblocktrans %}

{% blocktrans %}Hier siehst du deine Nachhilfestunden und Hausaufgaben. Du kannst Termine buchen, verschieben und absagen, deinem Nachhilfelehrer schreiben, Dokumente austauschen und an Online-Meetings teilnehmen. Welche dieser Funktionen freigeschaltet sind, legt dein Nachhilfelehrer fest.{% endblocktrans %}

{% blocktrans %}Wie aktiviere ich meinen Portal-Zugang?{% endblocktrans %}

{% blocktrans %}Du erhältst per E-Mail einen persönlichen Aktivierungslink. Klicke darauf und setze dein Passwort. Danach bist du sofort angemeldet. Der Link ist 7 Tage gültig. Ist er abgelaufen, bitte deinen Nachhilfelehrer um eine neue Einladung.{% endblocktrans %}

{% blocktrans %}Wie melde ich mich später an?{% endblocktrans %}

{% blocktrans %}Mit deiner E-Mail-Adresse und deinem Passwort auf der Anmeldeseite des Portals.{% endblocktrans %}

{% blocktrans %}Ich habe keine Einladung erhalten.{% endblocktrans %}

{% blocktrans %}Prüfe deinen Spam-Ordner. Ist die E-Mail dort nicht, schickt dir dein Nachhilfelehrer eine neue Einladung.{% endblocktrans %}

{% blocktrans %}Kann ich das Portal wie eine App nutzen?{% endblocktrans %}

{% blocktrans %}Ja. Unter{% endblocktrans %} {% blocktrans %}Profil{% endblocktrans %} {% blocktrans %}findest du „Zum Home-Bildschirm hinzufügen“. Danach öffnest du das Portal über ein eigenes Symbol auf deinem Handy.{% endblocktrans %}

{% blocktrans %}Termine buchen{% endblocktrans %}

{% blocktrans %}Wie buche ich einen Termin?{% endblocktrans %}

{% blocktrans %}Gehe zu{% endblocktrans %} {% blocktrans %}Termin buchen{% endblocktrans %} {% blocktrans %}(über das Dashboard oder den Kalender). Wähle ein Datum. Du siehst dann die freien Zeiten deines Nachhilfelehrers. Tippe auf eine Zeit und bestätige die Buchung. Im Feld „Thema / Nachricht“ kannst du angeben, was du in der Stunde besprechen möchtest.{% endblocktrans %}

{% blocktrans %}Welche Zeiten kann ich buchen?{% endblocktrans %}

{% blocktrans %}Zeiten innerhalb der Arbeitszeiten deines Nachhilfelehrers, die noch frei sind. Termine in der Vergangenheit lassen sich nicht buchen. Tippe erst auf einen Tag (oben in der Übersicht steht bei jedem Tag, wie viele Zeiten frei sind, oder wähle ein Datum im Feld „Datum wählen“), dann erscheinen darunter die freien Uhrzeiten zum Anklicken. Die Seite öffnet auf der ersten Woche, in der noch etwas frei ist; mit „Vorige Woche“ und „Nächste Woche“ blätterst du weiter. Uhrzeiten von heute, die schon vorbei sind, werden nicht angeboten.{% endblocktrans %}

{% blocktrans %}Was bedeuten die grauen „Belegt“-Felder?{% endblocktrans %}

{% blocktrans %}Sie zeigen Zeiten, in denen dein Nachhilfelehrer schon einen anderen Termin oder eine Blockzeit hat. Diese Zeiten kannst du nicht buchen.{% endblocktrans %}

{% blocktrans %}Warum kann ich eine Zeit nicht buchen, obwohl sie nicht als „Belegt“ markiert ist?{% endblocktrans %}

{% blocktrans %}Dein Nachhilfelehrer hält zwischen Terminen eine Pause ein und rechnet Fahrzeiten zu seinen Terminen. Zeiten, die dicht vor oder nach einem Termin oder einer Blockzeit liegen, werden deshalb nicht als frei angeboten. Wähle dann eine Zeit mit etwas mehr Abstand.{% endblocktrans %}

{% blocktrans %}Wie lange dauert ein gebuchter Termin?{% endblocktrans %}

{% blocktrans %}So lange, wie es in eurem Vertrag als Einheit vereinbart ist. Brauchst du eine längere Stunde, sprich das mit deinem Nachhilfelehrer ab.{% endblocktrans %}

{% blocktrans %}Warum soll ich Abstand zu anderen Terminen lassen?{% endblocktrans %}

{% blocktrans %}Manche Nachhilfelehrer bitten beim Buchen darum, etwa eine halbe Stunde Puffer zu ihren anderen Terminen zu lassen. So bleibt Zeit für die Vorbereitung. Das ist eine Bitte. Hat dein Nachhilfelehrer dagegen einen festen Mindestabstand eingestellt, zeigt das Portal Zeiten, die ihn unterschreiten, gar nicht erst als frei an.{% endblocktrans %}

{% blocktrans %}Warum steht dort „Online-Buchungen sind im Moment nicht möglich“?{% endblocktrans %}

{% blocktrans %}Dann nimmt dein Nachhilfelehrer gerade keine Buchungen über das Portal an. Sprich den Termin direkt mit ihm ab.{% endblocktrans %}

{% blocktrans %}Erfährt mein Nachhilfelehrer von meiner Buchung?{% endblocktrans %}

{% blocktrans %}Ja. Der Termin steht sofort in seinem Kalender. Außerdem bekommt er eine Benachrichtigung, sofern er sie nicht abgeschaltet hat.{% endblocktrans %}

{% blocktrans %}Verschieben & absagen{% endblocktrans %}

{% blocktrans %}Wie verschiebe ich einen Termin?{% endblocktrans %}

{% blocktrans %}Tippe unter{% endblocktrans %} {% blocktrans %}Stunden{% endblocktrans %} {% blocktrans %}oder im Dashboard auf den Termin und wähle{% endblocktrans %} {% blocktrans %}Verschieben{% endblocktrans %}{% blocktrans %}. Suche einen neuen Tag und eine freie Zeit aus. Ist an einem Tag nichts mehr frei, wähle einen anderen Tag oder die nächste Woche.{% endblocktrans %}

{% blocktrans %}Wie sage ich einen Termin ab?{% endblocktrans %}

{% blocktrans %}Öffne den Termin und wähle{% endblocktrans %} {% blocktrans %}Absagen{% endblocktrans %}{% blocktrans %}. Der Termin wird dann aus deinem Kalender und aus dem deines Nachhilfelehrers entfernt. Unter{% endblocktrans %} {% blocktrans %}Stunden{% endblocktrans %} {% blocktrans %}steht er danach bei „Abgesagte Termine“, mit dem Zeitpunkt der Absage.{% endblocktrans %}

{% blocktrans %}Welche Termine kann ich ändern?{% endblocktrans %}

{% blocktrans %}Nur geplante Termine. Eine Stunde, die schon stattgefunden hat, lässt sich im Portal nicht mehr verschieben oder absagen.{% endblocktrans %}

{% blocktrans %}Erfährt mein Nachhilfelehrer von einer Absage oder Verschiebung?{% endblocktrans %}

{% blocktrans %}Ja. Er bekommt eine Benachrichtigung, sofern er sie nicht abgeschaltet hat, und sieht die Änderung in seinem Kalender. Bei sehr kurzfristigen Änderungen gib ihm trotzdem direkt Bescheid, zum Beispiel über{% endblocktrans %} {% blocktrans %}Nachrichten{% endblocktrans %}.

{% blocktrans %}Bis wann muss ich absagen?{% endblocktrans %}

{% blocktrans %}Das Portal setzt keine Frist. Es gilt, was du mit deinem Nachhilfelehrer vereinbart hast. Frag ihn, wenn du unsicher bist, ob eine späte Absage berechnet wird.{% endblocktrans %}

{% blocktrans %}Der Termin gehört zu einer Serie. Was passiert beim Verschieben?{% endblocktrans %}

{% blocktrans %}Nur dieser eine Termin wird verschoben. Er gehört danach nicht mehr zur Serie. Die anderen Termine der Serie bleiben, wie sie sind.{% endblocktrans %}

{% blocktrans %}Serientermine{% endblocktrans %}

{% blocktrans %}Was sind Serientermine?{% endblocktrans %}

{% blocktrans %}Regelmäßig wiederkehrende Stunden, zum Beispiel jeden Montag um 16:00 Uhr. Deine Serien findest du unter{% endblocktrans %} {% blocktrans %}Serientermine{% endblocktrans %}.

{% blocktrans %}Kann ich selbst eine Serie anlegen?{% endblocktrans %}

{% blocktrans %}Das hängt davon ab, was dein Nachhilfelehrer freigeschaltet hat. Siehst du unter „Serientermine“ die Schaltfläche „Neue Serie“, wählst du Wochentage, Uhrzeit, Start und auf Wunsch ein Ende. Sonst sprichst du die Serie direkt mit ihm ab. Ist dein Nachhilfelehrer an einem Tag der Serie zu dieser Zeit schon belegt oder liegt die Uhrzeit außerhalb seiner Arbeitszeiten, wird dieser Tag ausgelassen, alle anderen werden gebucht. Termine, die schon vorbei sind, lässt Preceptly ebenfalls aus. Nach dem Anlegen siehst du, welche Tage ausgelassen wurden.{% endblocktrans %}

{% blocktrans %}Wie sage ich nur einen Termin einer Serie ab?{% endblocktrans %}

{% blocktrans %}Öffne den Termin und wähle „Nur diesen Termin absagen“. Die übrigen Termine bleiben bestehen.{% endblocktrans %}

{% blocktrans %}Wie beende ich eine ganze Serie?{% endblocktrans %}

{% blocktrans %}Unter „Serientermine“ mit „Serie beenden“ oder im Termin mit „Gesamte Serie absagen“. Alle kommenden Termine der Serie entfallen dann und stehen bei „Abgesagte Termine“. Stunden, die schon stattgefunden haben, bleiben erhalten.{% endblocktrans %}

{% blocktrans %}Stunden & Hausaufgaben{% endblocktrans %}

{% blocktrans %}Was bedeutet der Status einer Stunde?{% endblocktrans %}

  • {% blocktrans %}Geplant:{% endblocktrans %} {% blocktrans %}Der Termin steht an.{% endblocktrans %}
  • {% blocktrans %}Unterrichtet:{% endblocktrans %} {% blocktrans %}Die Stunde hat stattgefunden.{% endblocktrans %}
  • {% blocktrans %}Ausgefallen:{% endblocktrans %} {% blocktrans %}Die Stunde ist ausgefallen.{% endblocktrans %}
  • {% blocktrans %}Bezahlt:{% endblocktrans %} {% blocktrans %}Die Stunde ist abgerechnet und bezahlt.{% endblocktrans %}

{% blocktrans %}Eine Stunde steht auf „Unterrichtet“, hat aber nicht stattgefunden. Warum?{% endblocktrans %}

{% blocktrans %}Ein geplanter Termin wechselt automatisch auf „Unterrichtet“, sobald seine Endzeit vorbei ist. Wurde er vorher nicht abgesagt, gilt er deshalb als gehalten. Melde dich bei deinem Nachhilfelehrer. Er kann den Status berichtigen.{% endblocktrans %}

{% blocktrans %}Wo sehe ich, wann und von wem ein Termin gebucht wurde?{% endblocktrans %}

{% blocktrans %}Öffne den Termin. In der Zeile „Gebucht“ stehen der Zeitpunkt und das Konto, zum Beispiel „über das Portal von dir“ oder der Name deines Nachhilfelehrers. Das Konto wird seit dem 29.09.2026 gespeichert. Ältere Termine zeigen nur den Zeitpunkt.{% endblocktrans %}

{% blocktrans %}Wo finde ich meine Hausaufgaben?{% endblocktrans %}

{% blocktrans %}Im Dashboard unter „Letzte Stunden“ und auf der Detailseite der Stunde. Dort stehen auch Notizen, die dein Nachhilfelehrer zur Stunde geschrieben hat.{% endblocktrans %}

{% blocktrans %}Kalender{% endblocktrans %}

{% blocktrans %}Was bedeuten die roten „Belegt“-Blöcke im Kalender?{% endblocktrans %}

{% blocktrans %}Sie zeigen, dass dein Nachhilfelehrer zu dieser Zeit einen anderen Termin oder eine Blockzeit hat. Du siehst keine Details, also keinen Namen und kein Thema.{% endblocktrans %}

{% blocktrans %}Was bedeuten die blauen Blöcke?{% endblocktrans %}

{% blocktrans %}Das sind deine eigenen Stunden. Tippe darauf, um die Details zu sehen.{% endblocktrans %}

{% blocktrans %}Kann ich meine Termine im eigenen Kalender sehen?{% endblocktrans %}

{% blocktrans %}Ja. Unter{% endblocktrans %} {% blocktrans %}Profil{% endblocktrans %} {% blocktrans %}findest du bei „Kalender abonnieren“ einen persönlichen Link. Trage ihn einmal als Kalender-Abo in Google Kalender, iCloud oder Outlook ein. Neue Termine erscheinen dann von selbst. Der Kalender aktualisiert sich alle paar Stunden und ist nur lesend: Änderungen dort wirken sich nicht auf das Portal aus.{% endblocktrans %}

{% blocktrans %}Ich habe den Kalender-Link versehentlich weitergegeben. Was nun?{% endblocktrans %}

{% blocktrans %}Wähle im Profil „Link erneuern“. Der alte Link funktioniert dann nicht mehr, und du trägst den neuen in deinem Kalender ein.{% endblocktrans %}

{% blocktrans %}Online-Meeting{% endblocktrans %}

{% blocktrans %}Wie nehme ich an einem Online-Meeting teil?{% endblocktrans %}

{% blocktrans %}Läuft ein Meeting, zeigt das Dashboard „Meeting läuft – Jetzt beitreten“. Du kannst auch den Termin öffnen und „Meeting beitreten“ wählen.{% endblocktrans %}

{% blocktrans %}Dort steht „Kein Meeting aktiv“. Was heißt das?{% endblocktrans %}

{% blocktrans %}Dein Nachhilfelehrer hat das Meeting noch nicht gestartet. Sobald er es startet, kannst du beitreten. Wartest du schon im Warteraum, wirst du automatisch verbunden.{% endblocktrans %}

{% blocktrans %}Was brauche ich dafür?{% endblocktrans %}

{% blocktrans %}Einen aktuellen Browser, eine Kamera und ein Mikrofon. Ein Programm musst du nicht installieren. Beim ersten Mal fragt der Browser, ob er Kamera und Mikrofon nutzen darf. Erlaube das, sonst hört und sieht dich dein Nachhilfelehrer nicht.{% endblocktrans %}

{% blocktrans %}Bild oder Ton funktionieren nicht.{% endblocktrans %}

{% blocktrans %}Prüfe in den Einstellungen des Browsers, ob Kamera und Mikrofon für das Portal erlaubt sind, und lade die Seite neu. Hilft das nicht, probiere einen anderen Browser oder ein anderes Gerät.{% endblocktrans %}

{% blocktrans %}Nachrichten & Dokumente{% endblocktrans %}

{% blocktrans %}Wie schreibe ich meinem Nachhilfelehrer?{% endblocktrans %}

{% blocktrans %}Über{% endblocktrans %} {% blocktrans %}Nachrichten{% endblocktrans %} {% blocktrans %}im Dashboard. Dort siehst du auch seine Antworten.{% endblocktrans %}

{% blocktrans %}Wo finde ich Unterrichtsmaterial?{% endblocktrans %}

{% blocktrans %}Unter{% endblocktrans %} {% blocktrans %}Dokumente{% endblocktrans %}{% blocktrans %}. Dort lädst du Dateien herunter, die dein Nachhilfelehrer bereitgestellt hat.{% endblocktrans %}

{% blocktrans %}Kann ich selbst Dateien hochladen?{% endblocktrans %}

{% blocktrans %}Ja, zum Beispiel ein Foto deiner Hausaufgabe. Erlaubt sind PDF, Bilder (PNG, JPG), Word, Excel und Textdateien bis 50 MB.{% endblocktrans %}

{% blocktrans %}Warum kann ich keine weitere Datei hochladen?{% endblocktrans %}

{% blocktrans %}Dann ist die Zahl der Dateien für dich ausgeschöpft. Wende dich an deinen Nachhilfelehrer.{% endblocktrans %}

{% blocktrans %}Eltern & mehrere Kinder{% endblocktrans %}

{% blocktrans %}Brauchen Eltern und Kind getrennte Konten?{% endblocktrans %}

{% blocktrans %}Nein. Eltern und Kind nutzen gemeinsam ein Konto.{% endblocktrans %}

{% blocktrans %}Ich habe mehrere Kinder bei demselben Nachhilfelehrer. Brauche ich mehrere Konten?{% endblocktrans %}

{% blocktrans %}Das hängt davon ab, was dein Nachhilfelehrer freigeschaltet hat. Mit dem Familien-Zugang siehst du nach der Anmeldung alle Kinder auf einer Seite und wählst für jedes Kind Termine, Kalender, Dokumente und Nachrichten. Sonst hat jedes Kind ein eigenes Konto mit eigener E-Mail-Adresse.{% endblocktrans %}

{% blocktrans %}Sehen andere Familien unsere Daten?{% endblocktrans %}

{% blocktrans %}Nein. Du siehst nur die Daten deiner eigenen Kinder. Termine anderer Schüler erscheinen höchstens als „Belegt“, ohne Namen.{% endblocktrans %}

{% blocktrans %}Konto & Passwort{% endblocktrans %}

{% blocktrans %}Ich habe mein Passwort vergessen. Was jetzt?{% endblocktrans %}

{% blocktrans %}Gehe zur Seite{% endblocktrans %} {% blocktrans %}Passwort zurücksetzen{% endblocktrans %} {% blocktrans %}und gib deine E-Mail-Adresse ein. Du erhältst einen Link. Er gilt eine Stunde. Danach forderst du einfach einen neuen an.{% endblocktrans %}

{% blocktrans %}Wie ändere ich mein Passwort?{% endblocktrans %}

{% blocktrans %}Unter{% endblocktrans %} {% blocktrans %}Profil{% endblocktrans %} {% blocktrans %}bei „Passwort ändern“. Du brauchst dafür dein aktuelles Passwort.{% endblocktrans %}

{% blocktrans %}Wie ändere ich meine E-Mail-Adresse oder Telefonnummer?{% endblocktrans %}

{% blocktrans %}Unter{% endblocktrans %} {% blocktrans %}Profil{% endblocktrans %} {% blocktrans %}bei „Kontaktdaten“. Mit der E-Mail-Adresse meldest du dich an, und an sie gehen Benachrichtigungen.{% endblocktrans %}

{% blocktrans %}Wie schalte ich Push-Nachrichten ein?{% endblocktrans %}

{% blocktrans %}Im Profil unter „Benachrichtigungen“. Push-Nachrichten aktivierst du für jedes Gerät einzeln. Unterstützt dein Browser sie nicht, steht das dort.{% endblocktrans %}

{% blocktrans %}Wie lösche ich mein Konto?{% endblocktrans %}

{% blocktrans %}Wende dich an deinen Nachhilfelehrer. Er verwaltet die Portal-Zugänge seiner Schüler.{% endblocktrans %}

{% blocktrans %}Zeitzone & Uhrzeiten{% endblocktrans %}

{% blocktrans %}In welcher Zeitzone werden die freien Zeiten beim Buchen angezeigt?{% endblocktrans %}

{% blocktrans %}In deiner Ortszeit. Das Portal erkennt die Zeitzone über deinen Browser und rechnet die freien Zeiten deines Nachhilfelehrers um.{% endblocktrans %}

{% blocktrans %}Was passiert, wenn mein Nachhilfelehrer in einer anderen Zeitzone ist?{% endblocktrans %}

{% blocktrans %}Beim Buchen wird die gewählte Uhrzeit in seine Zeitzone umgerechnet und richtig gespeichert. Du musst nichts selbst ausrechnen. Ein Hinweis nennt dir beide Zeitzonen.{% endblocktrans %}

{% blocktrans %}Warum sehe ich manchmal eine Uhrzeit mit „(Tutor)“ in Klammern?{% endblocktrans %}

{% blocktrans %}Weichen eure Zeitzonen ab, zeigt die Buchung neben deiner Ortszeit auch die Zeit deines Nachhilfelehrers. So vermeidest du Verwechslungen.{% endblocktrans %}

{% blocktrans %}Datenschutz & Hilfe{% endblocktrans %}

{% blocktrans %}Sind meine Daten sicher?{% endblocktrans %}

{% blocktrans %}Alle Daten werden verschlüsselt übertragen (HTTPS). Du siehst ausschließlich Informationen zu deinem eigenen Unterricht. Daten anderer Schüler kannst du nicht einsehen. Einzelheiten stehen in der Datenschutzerklärung, die unten auf jeder Seite verlinkt ist.{% endblocktrans %}

{% blocktrans %}Wer sieht meine Nachrichten und Dokumente?{% endblocktrans %}

{% blocktrans %}Du und dein Nachhilfelehrer.{% endblocktrans %}

{% blocktrans %}An wen wende ich mich bei Fragen oder technischen Problemen?{% endblocktrans %}

{% blocktrans %}An deinen Nachhilfelehrer. Er kann das Problem an den Support von Preceptly weitergeben.{% endblocktrans %}
